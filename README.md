# BiliBuff - 哔哩哔哩｜B站效率与体验增强插件

上B站学点东西，有个Buff更顺手。

**BiliBuff** 是一个面向 B 站学习与日常浏览的效率和体验增强插件。推荐筛选、屏蔽视频、留白首页、观看统计，加上按需使用的 AI 计划分析、内容复核和评论区速读，让找内容、看视频、读评论更顺手。

## 推荐可以挑一挑

设置里有“想多看”和“想少看”两个区，填几个词就能开始。

比如最近在学摄影，可以把“摄影”“构图”放进想多看；总被剧透和抽奖带跑，就把它们放进想少看。扩展会根据视频标题和标签判断：喜欢的加上高亮，不想看的盖住封面，首页和播放页旁边的推荐都能照顾到。

平常可以保留没匹配到的推荐，顺便发现点新东西。临近考试、赶项目，或者今天实在经不起诱惑，就打开“只看偏好的内容”，让推荐范围再收紧一点。

挡住的视频仍然可以临时查看。偶尔想看开盲盒，点一下就行，规则也不用跟着改来改去。

## 首页太热闹，就给它留点白

推荐广告可以挡，首页大轮播也可以收起来。视频页右侧的推广卡片，同样有开关管着。

想干脆一点？开启**留白模式**，首页只留下搜索框。

## 规则懒得想，可以请 AI 搭把手

有时候只知道“最近想认真学点东西”，具体该填什么词，还真说不上来。

在“AI 计划分析”里写下近期计划，等观看和屏蔽记录攒够后，让AI开始分析。AI会结合这些记录和已有规则，给出筛选规则的增删词条的建议及理由；信息不够时，也可能问个小问题，帮忙把方向搞清楚。

建议出来后，挑自己认可的再采用。觉得它说得不对，放着就好。

另外还有一个 **AI 复核**：对已经按偏好放行的推荐视频，再看看它和近期计划是否相关。比如标题碰巧带着“学习”，内容却未必是你眼下想学的那一类，这种就让AI复核帮你搞定屏蔽。

## 评论太多，先速读

“评论区速读”以可拖动的悬浮窗呈现，翻看评论时也能保留分析在旁边。展开后，可以请 AI 整理主要讨论与不同观点，再挑出几条有价值的评论；点击即可定位楼层。

评论采集期间可以随时暂停，直接分析已采集的评论，也可以再点击“继续采集”接着读取。“检查更新”保留已有数据，核对分页并合并新增评论；检查中断时也不清空已取得的内容。完整与部分速读结果均可在刷新后恢复，部分结果注明覆盖范围；原始评论和采集进度仍只留当前页面。

不想用自己的模型服务，也能把全部或筛选后的评论复制、下载为带回复关系和来源链接的文本，交给网页AI或自己整理。

## 视频很长，先抓住重点

视频页右侧的“BiliBuff视频助手”提供字幕、总结、章节、问答和下载五个分页。字幕可以搜索、点击定位、跟随播放，也能复制或导出成纯文本、带时间戳文本和字幕文件。

AI生成视频总结，AI生成章节并标记疑似广告部分；章节按真实字幕时间跳转，视频口播广告可自动跳过。可以围绕当前视频提问，并提供引用回到关键视频位置。

提供部分视频下载服务。

## 看了什么，留个小账本

设置页能看到累计高亮、屏蔽和观看的数量，同一视频在同一类统计里只记一次。

至于播放时有没有认真听，还是你自己最清楚~

## 装好插件后，从几个词开始

点击浏览器工具栏里的扩展图标，或 B 站页面右下角的“BiliBuff 设置”，就能打开设置页。

1. 在“想多看”里填几个最近关心的主题。
2. 在“想少看”里填几个经常让你跑偏的词。
3. 回 B 站看看效果，再慢慢调整。词条和开关修改后会自动保存。

主题有浅色和深色，也能跟随系统。规则、计划和记录保存在本机，可以导出备份，再导入另一个浏览器。

本项目只提供浏览器扩展，支持 Chrome 和 Edge。
