## 常见页面与功能结构地图（2026-10-14）

复用当前浏览器会话，检查首页、普通视频、搜索、热门、动态、作者投稿、收藏、历史、稍后再看、番剧入口及直播入口。读取页面结构和站点已发出的请求路径；不保存账号标识、个人内容清单、登录请求头、追踪参数或密钥。没有点击点赞、投币、收藏、关注、评论、发送弹幕、删除历史或付费按钮。播放类入口可能自动播放；诊断页完成检查后暂停媒体并关闭。

以下数量只是单次页面样本，不作为固定数量或接口稳定性承诺。

| 页面 / 功能 | 实测结构 | 当前扩展覆盖与实现含义 |
| --- | --- | --- |
| 首页 | 10 张 `.bili-feed-card .bili-video-card`【普通推荐卡片】，4 张 `.floor-card.single-card`【楼层推荐卡片】，1 个 `.recommended-swipe`【推荐轮播】 | 当前覆盖普通卡片、楼层单卡和轮播；骨架节点没有标题时不处理 |
| 顶部导航 | `.bili-header__bar`【搜索与账号功能所在的导航条】 | 保留搜索、动态、收藏、历史入口；不能把整个顶部当成推荐区域 |
| 普通视频相关推荐 | 20 张 `.video-page-card-small .card-box`【横向相关推荐卡片】 | 当前覆盖；与主播放器、合集选集分别处理 |
| 视频页推广 | `.video-card-ad-small-inner .ad-report`【推广卡片内容层】下有广告域名链接 | 当前卡片扫描范围没有覆盖它；首页广告开关不等于播放页推广已屏蔽 |
| 合集选集 | `.video-pod`【合集容器】、`.video-pod__item`【选集条目】 | 本轮 6 集均未进入遮罩范围；属于用户主动继续学习的入口，不宜默认当成随机推荐屏蔽 |
| 播放控制 | `.bpx-player-container`【主播放器容器】；`data-screen`【普通、网页全屏等显示模式】 | 可见播放、上一集、下一集、倍速、字幕、清晰度、音量、宽屏、网页全屏、全屏和画中画入口；本轮未逐一切换这些模式 |
| 简介与主题标签 | `.tag-link`【主题标签链接】，本样本 8 项 | 与推荐理由、活动词区分；能辅助解释判定，不意味着标签一定代表真实教学内容 |
| 评论 | `bili-comments`【评论组件】内部有影子根节点 | 常规文档扫描不会进入组件内部；如果以后做评论折叠，需要单独适配，不能扩大通用视频卡片选择器 |
| 搜索 | `.search-page`【搜索主体】、`.search-tabs`【内容类型页签】，42 张 `.bili-video-card`【结果卡片】；标题仍为 `.bili-video-card__info--tit`【卡片标题】 | 当前没有搜索子域名权限；有综合、视频、番剧、影视、直播、专栏、用户页签，以及排序、日期、时长筛选；必须按内容类型区分 |
| 热门 | `.popular-list`【热门列表】，20 张 `.video-card`【热门卡片】，内容层 `.video-card__content`【卡片内容】 | 当前未过滤；不能直接复用首页卡片结构 |
| 动态 | `.bili-dyn-list`【动态列表】，20 条 `.bili-dyn-item`【动态条目】，11 张 `.bili-dyn-card-video`【视频投稿卡片】，标题为 `.bili-dyn-card-video__title`【投稿标题】 | 当前没有动态子域名权限；视频投稿仅为部分条目，文字、转发、追番不应套用普通视频标签查询 |
| 作者投稿 | `.space-upload`【投稿页主体】、`.upload-video-card`【投稿卡片】，本轮 40 张 | 标题改用 `.bili-video-card__title`【新卡片标题】，虽然卡片仍叫 `.bili-video-card`【视频卡片】，现有首页标题读取方式不适用 |
| 收藏 | `.favlist-main`【收藏主体】，39 张 `.bili-video-card`【收藏条目】，标题为 `.bili-video-card__title`【新卡片标题】 | 当前没有空间子域名权限；用户主动收藏的内容宜默认保留，不自动按首页严格模式遮蔽 |
| 历史 | `.history-record`【历史页主体】、`.history-list`【历史列表】，20 张 `.history-card`【历史条目】 | 标题同样使用新卡片结构；当前未过滤，也没有使用历史接口替代实际观看计时 |
| 稍后再看 | `/list/watchlater`【稍后再看播放路由】，`.playlist-container`【播放列表容器】和主播放器 | 这是独立播放页，会自动选择内容；当前只识别普通视频路由，因此这里不会累计观看，也不会过滤推荐 |
| 番剧入口 | `/anime/`【番剧频道】链接指向 `/bangumi/play/ss…` 或 `/bangumi/play/ep…`【季或剧集播放路由】 | 不属于普通视频路由；不能只靠普通视频编号适配选集、会员权限和观看统计 |
| 番剧播放 | 样本 `/bangumi/play/ss34437`【公开番剧季播放入口】也包含主播放器，但选集类名使用 `PlayerEpisodePanel_episodeRow…`【带构建后缀的选集行样式】 | 不能把同样存在主播放器当作已支持计时；选集的构建后缀不宜当成稳定选择器 |
| 直播入口 | `live.bilibili.com`【直播子域名】；首页房间卡片大量使用工具样式类，链接以房间编号定位 | 房间编号与普通视频编号不同；站点直播接口域名也不同，需要独立方案和必要权限 |
| 直播间 | `#live-player`【直播播放器】、`.chat-history-list`【弹幕记录区】、`.chat-input-ctnr`【弹幕输入区】和 `.gift-panel`【礼物区】 | 当前未接入；不要因需要专注就自动修改弹幕、礼物或关注行为 |

顶部收藏、历史、动态、消息均有独立入口。仅检查入口和页面结构，没有展开读取私信内容。分辨率、字幕、单集循环、自动开播、镜像、关灯等播放器选项本轮只确认存在，不代表已验证它们与扩展的全部组合。

## 接口路径与后续开发优先级（2026-10-14）

以下只记录浏览器已发出的路径，不重放带登录状态的请求，不将这些内部接口视为承诺稳定的开放接口：

| 观察到的路径 | 用途与限制 |
| --- | --- |
| `/x/polymer/web-dynamic/v1/feed/all`【动态流接口】 | 动态列表；不同内容类型需要独立处理 |
| `/x/polymer/web-dynamic/v1/feed/all/update`【动态更新接口】 | 动态更新检查；扩展未调用 |
| `/x/v3/fav/folder/created/list-all`【收藏夹列表接口】 | 收藏目录；扩展未读取其响应或保存收藏内容 |
| `/x/v3/fav/resource/list`【收藏条目接口】 | 收藏夹内资源；扩展未调用 |
| `/x/v2/medialist/toview/web`【稍后再看列表接口】 | 列表播放入口已使用；路由与普通视频页不同 |
| `/x/web-interface/archive/related`【相关视频接口】 | 本轮稍后再看页使用；推荐仍需与播放列表区分 |
| `/x/player/wbi/playurl`【视频播放地址接口】 | 普通点播媒体地址；无需为现有过滤功能主动请求 |
| `/x/player/wbi/v2`【播放器信息接口】 | 已观察到请求，字幕等具体响应字段本轮未解析 |
| `/pgc/view/web/ep/page`【番剧剧集页面信息接口】 | 本轮番剧播放页使用；不同于普通视频详情接口 |
| `/pgc/season/web/related/recommend`【番剧相关推荐接口】 | 本轮番剧播放页使用；扩展未调用 |
| `api.live.bilibili.com/xlive/web-interface/v1/index/getListV2`【直播首页列表接口】 | 直播首页使用；扩展目前无该域名权限 |
| `api.live.bilibili.com/xlive/web-room/v2/index/getRoomPlayInfo`【直播播放信息接口】 | 直播媒体使用；不能套用普通点播计时与标签编号 |

搜索初始结果可能来自页面内初始数据；本轮资源记录中只看到搜索默认词请求，不能据此推断搜索结果接口的构造。历史、番剧、直播间的完整请求参数、响应字段和交互流程未穷尽。

后续建议，均不属于此次修复已实现的功能：

1. 优先补齐视频页明确推广卡片，继续保留原尺寸和临时查看能力；先覆盖实际广告容器，再验证广告开关是否立即生效。
2. 支持稍后再看和收藏列表播放的观看计时，统一读取当前播放内容身份；保持分集、切换、暂停和倍速的计时语义。当前仅按普通视频路径读取编号会漏计。
3. 热门可考虑单独可选适配。用户后来明确要求搜索结果保留原样，因此搜索不接入过滤规则，也不为此增加搜索子域名权限。
4. 再考虑动态和作者投稿，按明确的普通视频卡片定位；每种页面保留自己的标题与容器读取方式，避免全站通用选择器误伤导航、合集和评论。
5. 收藏、历史默认保留，未来可以提供判定说明或可选过滤；不因它们使用相同卡片类名就自动接入首页规则。
6. 番剧、直播作为独立内容类型规划；主题标签、季/集/房间身份、权限和观看统计均需重新定义，不能把首页楼层卡片标题匹配当作完整适配。

持续验收重点：冷启动导航完整、首页加载和滚动、普通视频直达与合集切换、规则更新、播放器显示模式、动态内容身份变化，以及扩展失效清理。此次没有新增站点权限或实现这些扩展方向。

## 初始调查边界与复查方式（2026-10-13）

- 未验证批量查询标签的接口；目前按单个视频查询并缓存。
- 未验证封面内容识别、模型分类、字幕获取或分区映射。
- 没有保存登录凭据、完整请求头、广告追踪数据或个人账号信息。
- 新问题优先查看[调查导航](调查导航.md)中的对应专题和现有代码；只有站点结构变化、接口失败或新需求涉及未验证信息时再定向检查。
- 复查时读取少量公开视频样本，记录日期、参数、响应结构和结论；不要复制敏感请求头。
- 浏览器联调连接已解决：使用现有会话。不要为了重复检查改动全局工具配置或新建隔离登录会话。
