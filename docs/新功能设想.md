# AI帮你刷
AI帮你刷视频，自动选择你计划内可能感兴趣的视频。

# 留白模式增加AI帮刷
搜索框下增加AI帮刷得到的推荐的视频

# 重构项目所有图标，使项目更美观
已经引入的新图标库，lucide-react @lobehub/icons-static-svg；绝大部分手绘图标可以重构；极小部分已经牵连许多功能的重要图标可以留着

# 评论区速读
评论区速读自动速读时间可自行设定，默认3min

评论区速读卡片默认出现位置更改为图中的位置，视频助手左侧，视频大标题下侧。

如果有已经存在的视频助手总结，可以加入到速读上下文，更精准。该功能手动勾选开启（并记忆勾选，但如果没有总结/无法总结，勾选了等于没勾选。
