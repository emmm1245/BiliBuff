# 扩展安装与迁移

2026-10-16视频助手更新新增下载与B站媒体资源访问权限。构建后在扩展管理页重新加载；若浏览器显示新增权限提示，确认后刷新视频页。视频助手的字幕、总结、章节和问答属于本机缓存，不包含在普通配置备份中。

[文档目录](../README.md)

本项目只提供浏览器扩展，支持桌面版 Chrome 和 Edge，使用现代扩展规范。支持首页、楼层推荐、播放页相关推荐过滤、广告与轮播控制、实际播放计时、累计统计、手动模型分析、备份与迁移，以及默认关闭的偏好内容 AI 复核、评论区速读和文本导出。搜索、动态、热门和独立直播、番剧播放页仍不适配。

视频页右侧推广卡片也受广告开关控制；遮罩原因可在“内容过滤 → 广告与遮罩”中开启，默认关闭。“稍后再看”和收藏夹列表播放支持观看统计，列表内容保留原样。搜索页是用户主动查找内容的入口，本项目不对搜索结果应用规则。

装好后继续看[推荐过滤与留白首页](推荐过滤与留白首页.md)，需要模型功能时看[AI服务与计划分析](AI服务与计划分析.md)。

## 安装

需要 Node.js【开发工具运行环境】22.13 或更高版本，以及 pnpm【依赖管理工具】。以下命令由用户执行；从项目根目录进入扩展目录后，再安装、检查和构建：

```powershell
cd extension
pnpm install
pnpm check
pnpm build
pnpm build:edge
```

项目已包含依赖锁文件，后续应提交并保留。若包管理器提示依赖构建脚本未获允许，按提示处理后重新执行检查；不要把缺少构建结果当作安装成功。

Chrome：打开浏览器的扩展管理页面，开启开发者模式，选择“加载已解压的扩展程序”，选择扩展目录下 `.output/chrome-mv3`【Chrome 安装目录】。

Edge：打开浏览器的扩展管理页面，开启开发人员模式，选择“加载解压缩的扩展”，选择 `.output/edge-mv3`【Edge 安装目录】。

点击工具栏扩展图标，或 B 站页面右下角“BiliBuff 设置”，进入独立设置标签页。建议使用当前稳定版浏览器。更新时重新构建，在扩展管理页点击重新加载，再刷新 B 站页面。

长期使用请保留安装目录和扩展身份，使用重新加载更新；删除扩展会清除它的本地数据，更新前可导出备份。开发模式的浏览器配置与日常安装的数据不应混用。

## 本地存储用量

扩展声明 `unlimitedStorage`【解除扩展本地存储配额的权限】，适用于桌面版 Chrome 和 Edge，实际可用容量仍受磁盘剩余空间限制。已有安装需要重新构建并在扩展管理页重新加载后生效。

在“数据与维护 → 本地存储”查看估算合计、设置与速读缓存用量、数据库等估算占用及权限状态。进入该设置页和切回页面时更新，也可点击“刷新用量”。数据库统计包含累计记录、标签与复核缓存、调试日志等，并可能包含浏览器管理开销；估算值更新可能稍有延迟，不等同于精确磁盘占用。

项目自身的壁纸大小、速读缓存数量、标签与复核缓存数量及有效期限制保持不变。

## 备份与浏览器间迁移

1. 在原浏览器的扩展设置页导出数据；密钥默认不导出，可自行选择。
2. 在目标浏览器安装扩展，在“数据与维护 → 备份与迁移”中选择备份，检查摘要，确认导入。
3. 导入替换规则、计划和上次建议，累计记录按类型与视频合并并保留较新项。无密钥字段时保留本机密钥；空密钥明确移除密钥。
4. 刷新目标浏览器已打开的 B 站页面，确认规则和记录正确。

Chrome 与 Edge 之间也使用此备份迁移；没有自动跨浏览器同步。未保存的规则草稿、标签缓存、临时查看和未达标的播放计时不导出。
