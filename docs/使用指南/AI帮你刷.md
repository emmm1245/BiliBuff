# AI帮你刷

[文档目录](../README.md)

在“日常功能 → AI帮你刷”选择服务与模型，填写共用的近期计划，再开启功能。简称或内容边界不清时，可填写一次“推荐范围补充”，随配置保存和备份；不强制回答额外问题。开启期间自动强制使用留白首页，推荐放在搜索框下；关闭后恢复原来的首页选择。默认关闭，旧配置不会自动开启。

首次进入自动选片，已有结果优先从本机恢复，超过12小时会在进入首页时尝试更新。“换一批”重新找片，“停止”中止本轮；等待和失败时保留上一批。模型失败不自动重试；来源暂时故障可以在本轮预算内补试。请保持首页打开，首页选片期间查询后台进度；浏览器关闭或后台意外终止后，再次打开会提示重选。

卡片显示B站原封面、标题、作者、发布日期和时长，不附推荐理由。选中课程具体分P时，标题附分P名称，时长对应该P，链接直接打开该P；目录定位不代表已核验该P字幕。作者右侧提供正拇指、倒拇指，再点一次可取消。赞踩只影响本功能，不操作B站点赞、投币、收藏或“不感兴趣”。点踩卡片变淡并保留取消入口，后续批次排除该视频。

## 怎样选片

1. 从原计划整理通用目标、主题、明确排除项、内容形式和不确定边界，不预设用户在备考或只想学习。简称未在原文展开时保留原文，不把猜测的组成写成固定范围；原计划始终优先。结构化边界仅作辅助，不确定项不等于新增禁令。
2. 模型每轮规划最多4项搜索，包含关键词、意图、主题、排序和备用表达，并读取最近查询的实际效果。每个查询和排序独立管理页码，新查询从第一页开始；成功后才推进，近期投稿方向超过6小时重新取第一页。成功但无新增时可用备用表达，请求失败不代表该主题无内容。融合B站个性首页、计划搜索，以及明确点赞视频的相关推荐。来源交错合并后，每轮最多处理100条候选；排除近7天最多200条已展示、最近300条本地观看和已记住的点踩视频，遵守现有词条与偏好优先设置。未点击不算不喜欢。
3. 初选最多18条，读取简介、真实标签、完整分P标题、总集数、总时长和各P时长。字幕只尝试第一P，最多60个分散片段，不逐P读取。第一P导学不能否定后续课程，长视频、多分P只作内容充实的辅助信号。
4. 每6条一组分别判断主题范围、内容用途和证据充分程度，只发布明确符合计划且证据足够的真实视频。第一P字幕仅能证明第一P；后续分P只能由模型明确依据目录推荐，错误归属的字幕证据不会发布，也不因此追加读取后续字幕。没有字幕不直接淘汰；信息不足不冒充完整核验。相关性优先，不为数量和新鲜感放宽要求。
5. 多个核验组或合格候选超过12条时，最多增加一次全局精选，统一一级主题、具体知识点和内容用途，在所有合格候选与缓存之间比较优先级；失败时采用确定性的主题交错排序，不丢弃已核验内容。每批最多12条，同作者最多2条、同一规范化知识点最多3条。不足时结合本轮供给调整搜索方向，最多采集3轮（包含首次），避免只核验首批18条就结束。语义归一仍受模型判断影响，不等于完全消除了同义主题或重复投稿。
6. 已核验合格但未展示的内容最多储备36条，保存3天；池子足够时直接组成新批次，不重复调用模型。计划、模型或相关规则变化时原池子失效。已展示内容7天后、或超出200条上限后允许再次进入候选；点踩独立保留。

## 补充与错误处理

每次刷新所有B站网络请求合计最多180次，共享最多两路并发和至少100毫秒的启动间隔。来源采集仍最多24次（包含补试）；分项上限：首页3次、搜索18次、关联3次，详情、标签、第一P播放器、字幕各54次。分项上限不能突破180次总上限；标签缓存命中不发送请求。

412、429及已识别的平台访问限制立即冷却对应来源10分钟，不密集补试，等待中的同源请求也会停止发送。其他暂时网络、超时或服务错误最多补试2次，分别退避1.5秒、4秒，连续故障进入冷却；非暂时性错误不反复请求。冷却保存在本次后台运行期间。最多3轮、每轮最多18条取证以及整轮时间上限共同限制工作量。

单次模型等待上限3分钟，整轮上限6分钟。已有合格新内容时，后续来源或模型失败不覆盖该结果，也不向用户展示内部来源警告；没有新内容时保留旧批次并给出简短结果提示。明确停止、计划改变时不发布迟到结果。预算内补充不保证一定凑足12条。

后台控制台及本机最近20轮选片记录包含每条查询的返回、去重、新增、过滤、初选、核验与发布贡献，以及请求状态、证据分布、阶段耗时和模型实际用量。未返回完整用量时标记统计不完整，不将缺失当作零费用。另保留最近7天最多60条查询效果，供后续规划和独立分页复用；同视频可能命中多条查询，贡献不能直接相加作为视频总数。

原有AI日志导出同时包含有界选片诊断，不含密钥、Cookie、认证头或额外字幕正文；清除日志不会清除赞踩、候选池或功能性查询记忆，迟到选片不会恢复已清除诊断。模型原始日志仍使用已有AI日志开关。

## 数据与验证

开启后，计划、偏好词、最近最多40条赞踩对应的标题和标签、最近40条已推荐标题、可选范围补充、查询效果摘要、候选公开文字、完整目录和第一P字幕抽样会发送给所选AI服务。登录凭据仅用于B站，不发送给模型。每次模型调用可能计费；结构化边界在上下文不变时复用。事实核验只发送计划边界与必要证据，词条过滤在本地执行，偏好与近期推荐主要用于搜索规划和全局精选。关闭思考时小型结构化任务最多使用8192输出词元，用户设置更低上限时保留；不修改保存的模型配置，开启思考时沿用其设置。

推荐批次、近7天最多200条展示历史、最多500条赞踩、小型待推荐池和最近20轮诊断保存在本机独立存储；不改变观看统计。普通备份包含开关和模型配置，暂不包含推荐批次和赞踩记忆。推荐缓存不保存字幕正文。

2026-10-18已做离线流程、类型及静态检查，并用四类计划读取136条真实候选，为63条内容读取目录、时长和第一P字幕。时长均衡额外对照收益有限，正式功能暂不加入固定比例或时长均衡排序，时长仍参与内容判断。实验不能代表准确率或长期满意度。源码提示的真实调用与已安装扩展不是同一轮端到端验证；本次未构建或重新加载新版，来源补试主要经离线验证，新增全局精选、查询反馈和统一预算的验证见记录；搜索真实对照遇到412并停止，尚不能证明召回率或长期推荐质量提升。
