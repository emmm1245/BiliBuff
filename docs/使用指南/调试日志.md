# 调试日志

[文档目录](../README.md)

用于排查模型请求。模型服务与功能配置见[AI服务与计划分析](AI服务与计划分析.md)。

## 调试日志

在“数据与维护”底部展开“调试日志”，默认关闭。开关独立保存，不影响规则和模型配置；开启后记录新发起的计划分析（含每轮澄清）、通用复核、阿里云决策复核和评论速读请求。

每条日志包含功能、开始时间、服务地址、完整请求输入、模型原始输出、耗时、响应状态和错误。流式输出保留原始事件及服务返回的思考内容，接收期间持续保存；取消或断流时保留已收到的内容。未完成的请求也可以下载，结束状态标记为进行中。模型缓存命中不产生新请求日志。

点击“下载日志”导出全部记录为 `.json`【结构化文本文件】，点击“清除日志”删除已有记录；清除不会关闭开关，进行中的旧请求不会把已删除的日志写回。关闭后不再记录新请求，已有请求继续补全日志，已有记录仍可下载或清除。

日志只保存在本机，不保存认证请求头和配置密钥，也不进入普通设置备份。内容可能包含近期计划、观看样本、规则、评论正文和模型输出，分享前检查内容；调试完成后可关闭并清除日志。未构建加载新版前，现有安装版不会出现这个入口。
