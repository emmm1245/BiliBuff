# 运行日志

[文档目录](../README.md)

用于排查选片、视频助手、评论速读及数据维护操作。模型服务与功能配置见[AI服务与计划分析](AI服务与计划分析.md)。

## 查看与筛选

在“数据与维护”底部展开“运行日志”。日常诊断默认记录关键操作的时间、功能、结果、耗时和必要原因，不保存模型输入输出正文。信息分为错误、警告、信息和调试四级；主动取消单独标记，不当作失败。可以按功能、级别、最近24小时或7天筛选，并搜索功能、步骤或操作编号；列表每页20次操作。

展开一次操作可查看步骤和所属模型调用。AI选片会关联本轮模型调用、B站请求与选片汇总；视频总结、章节、问答和评论速读会关联生成请求，并记录结果保存是否成功。模型请求成功不等于整个任务保存成功，两者分开显示。设置、计划保存，备份导入导出，视频信息、字幕、下载资源读取及缓存清除也会记录结果。其余B站请求仍可通过完整导出的接口诊断查看。

日志面板展开且页面可见时每5秒刷新，收起后停止轮询，也可手动刷新。浏览器停止后台或页面关闭后，请求可能来不及保存结束状态，因此“进行中或已中断”不能当作仍在执行。

## 完整模型记录

“记录 AI 详细内容”默认关闭，沿用原调试开关，独立保存且不影响规则和模型配置。开启后记录新发起的计划分析（含每轮澄清）、两种AI复核、评论速读、视频总结、章节、问答及AI选片请求。模型缓存命中不产生新请求记录。

每条原始记录包含功能、服务地址、实际请求输入、原始输出、耗时、响应状态和错误；流式输出包含原始事件及服务返回的思考内容，接收期间持续保存。取消、断流或解析失败保留已收到的内容；展开模型调用后按需读取原始记录，进行中的记录也可查看或导出。旧版记录仍可随完整日志导出。

诊断摘要保留最近7天，最多500条（含子任务）、约2MB；每条最多60个步骤且总计约4KB，超出后省略较早步骤并标注数量。模型原始记录保留最近3天，最多50条、合计约10MB；输入和输出各最多262144字符，超长输入保存较短预览，截断会明确标记。限制仅影响日志，不截断模型实际输入或业务收到的响应。过期和容量淘汰在日志读写时执行。

## 导出与清除

“导出日志”下载 `.json`【结构化文本文件】，包括操作摘要、原始模型记录、B站请求诊断、选片轮次，以及扩展和浏览器版本。“导出文字摘要”下载 `.txt`【可直接阅读的文本文件】，只含操作摘要与步骤，不含原始模型正文。每次操作也可单独导出，只带该操作及其子任务已关联的记录；旧版及未关联请求不会混入单次操作导出。

“清除日志”同时清除以上记录，不关闭详细调试开关，不删除业务缓存、反馈或仍有效的来源冷却。进行中的旧任务不能恢复已清除的诊断，旧操作随后发起的模型子请求也不会重新保存原始记录。关闭详细调试后，已有请求继续补全记录，已有记录仍可查看、导出或清除。

日志仅保存在本机，不自动上传，也不进入普通设置备份。日志读取、导出与清除仅开放给扩展设置页，B站网页不能读取。摘要去除地址查询参数及常见认证信息；原始模型正文可能包含近期计划、观看样本、规则、评论和字幕，分享前请检查内容。未构建加载新版前，现有安装版不会出现新界面。

## B站接口诊断

下载文件还包含 `biliNetwork`【B站请求诊断】：视频助手、标签读取以及AI选片最近200条请求的时间、来源、接口路径、是否实际发送、耗时、网络状态、业务码、错误类型与冷却截止时间。这里只记录诊断摘要，不记录查询参数、签名、Cookie【浏览器登录与标识信息】或响应正文；不依赖模型日志开关，也不增加模型调用。

访问限制会暂停相应来源10分钟；视频和标签通用读取连续3次网络、超时或服务器错误后短暂暂停1分钟，AI选片原有预算和连续失败冷却规则继续保留。不同来源分别处理，命中的标签缓存仍可使用。视频助手与AI选片共用相关来源的限制状态，重新加载扩展也会保留已记录的冷却。

“清除日志”同时清除这些诊断和选片轮次记录，保留仍有效的冷却及业务缓存。清除时尚未结束的B站请求不会恢复旧诊断；若其随后触发限制，仍会保存冷却，防止持续请求受限来源。
