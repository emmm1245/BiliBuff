## 设计方向

- **熟悉**：参考 B 站的配色、细边框、圆角和操作习惯。使用自己的扩展名称与图标，不把设置页做成首页推荐流。
- **轻松**：标题说清用途，说明只补充必要条件。少量轻松语气可用于辅助文案，错误和操作结果保持直接。
- **省心**：普通编辑自动保存，不要求用户寻找“保存设置”。保存状态真实可见，失败后输入仍在。
- **精简文案**：优先用清晰的标题、字段标签和操作名称表达用途。功能的小字描述能省则省，确有必要时也只简略说明用途，不追求精确、完整地解释功能，不向用户披露技术细节。详细的技术说明写在面向开发者的文档或代码注释中。不堆叠口号、重复状态、解释性页脚和空态说明；影响操作判断、错误处理或必要限制的信息保留简短提示。
- **克制**：主要内容用中性底色，蓝粉用来引导操作和区分规则。避免大面积渐变、玻璃效果、厚阴影、频繁或大范围的装饰性动画和满屏强调色。

设置页的视觉改动不应顺带改变推荐过滤逻辑、模型调用条件、站点遮罩结构或备份格式。这些功能的边界见[推荐过滤与留白首页](../使用指南/推荐过滤与留白首页.md)。

## 组件库接入

2026-10-17确认采用 shadcn/ui【基础界面组件体系】与新版 AI Elements【AI交互组件方案】，配合 Streamdown【流式Markdown展示】和 Tailwind CSS【样式生成工具】逐步替换自有界面。按需引入组件源码并统一主题，保留B站蓝粉、中性底色、主要布局和现有交互含义，不直接照搬模板外观。

设置页、视频助手、评论悬浮窗和留白首页逐步组件化；推荐遮罩、播放器接入、原页评论定位继续适配原站节点。网页内组件的主题、样式和弹层留在扩展隔离区域，验证焦点、字号、全屏及卸载清理。组件化不能改变自动保存、调用条件、引用校验或数据格式。

## 页面组织

桌面布局采用左侧导航、右侧内容。导航依次为“内容过滤”“首页外观”“AI帮你刷”“评论速读”“视频助手”“AI 计划分析”“AI 服务”“数据与维护”；前六项归入日常功能，后两项归入配置与维护。默认打开内容过滤，外观切换放在侧栏底部。页头只显示页面标题与保存状态，不重复添加上级标题和泛泛的用途口号；底部保留本地存储说明及操作反馈。

| 分区 | 内容顺序 | 主要操作 |
| --- | --- | --- |
| 内容过滤 | 想多看与想少看；撤销删除；筛选方式；广告与遮罩；AI 复核 | 编辑词条、设置匹配与遮挡、配置复核 |
| 首页外观 | 留白模式；首页壁纸与预览；原版首页轮播 | 切换留白、添加或恢复壁纸、隐藏轮播 |
| AI帮你刷 | 独立开关；近期计划摘要；选片服务与模型 | 配置首页推荐、跳转共用计划与AI服务 |
| 评论速读 | 自动速读；分析范围；服务与模型 | 设置触发条件、评论数量、模型 |
| 视频助手 | 常用自动功能；总结、章节和问答的独立模型配置 | 配置自动行为、模型与生成参数 |
| AI 计划分析 | 近期计划、样本进度与开始按钮；分析过程或补充问题；分析结果；默认折叠的分析设置 | 发起分析、回答问题、采用建议、调整模型与样本参数 |
| AI 服务 | 已配置服务；添加兼容服务 | 管理连接、密钥和站点授权 |
| 数据与维护 | 累计统计；备份与迁移；本地存储；默认折叠的调试日志 | 查看记录数量、导入导出、排查问题 |

“想多看”和“想少看”各保留标题词、视频标签两组输入，共四组词条。两类在规则页分别用蓝色和粉色区分，同时保留文字标题；分析结果可以使用“偏好内容”和“避开内容”表达同一含义。

AI 服务集中管理连接和密钥，以可展开的服务卡片区分 DeepSeek 官方与自定义兼容服务。添加后的空配置自动展开，基础地址和名称在宽屏并列、窄屏单列；手动分析与通用复核使用相同的服务和模型选择控件。服务授权通过独立按钮触发，不在自动保存时弹出浏览器授权。使用中的兼容服务先切换后才能删除；密钥保留眼睛按钮和清空删除语义。技术生成参数默认折叠，DeepSeek 专用参数仅在使用官方服务时显示。

新功能优先归入已有分区。只有内容职责确实独立、现有结构无法清晰容纳时，再考虑增加导航。

近期计划只在计划分析页编辑，AI 复核显示同一计划的两行摘要，并提供编辑入口。各项功能在自己的面板选择模型，通过“管理 AI 服务”进入统一连接配置；阿里云实验性决策模式的专用密钥和业务空间仍在复核设置中管理。切换面板不重置草稿或中断分析；分析期间切到其他面板时显示返回入口和暂不可编辑的原因。

## 尺寸与布局基准

以下数值对应现有实现，用于保持整体比例；局部微调应服务于阅读和操作，不需要把每个数值冻结。

| 项目 | 基准 |
| --- | --- |
| 字体 | 微软雅黑优先，系统字体兜底；正文 14 像素、行高 1.65 |
| 标题 | 页面标题 28 像素、卡片标题 18 像素、小标题 14 像素；主要标题字重 600 |
| 次级文字 | 必要说明 14 像素；计数、时间等元信息 13 像素，不用更小文字堆叠功能解释 |
| 侧栏 | 宽 232 像素，细右边框；高度不足时内部可滚动 |
| 主内容 | 整体最大宽度 1512 像素；宽窗口顶部留白 44 像素、右侧 56 像素 |
| 卡片 | 圆角 10 像素、边框 1 像素；内边距约 26 × 28 像素 |
| 表单与按钮 | 圆角 6 像素；输入框内边距 10 × 12 像素；按钮约 8 × 16 像素 |
| 间距 | 卡片及双栏间距约 20 像素；表单组间距约 20 像素 |
| 动效 | 普通悬停和开关过渡约 150 毫秒；尊重系统减少动态效果的设置 |

响应式按以下层级收缩：

- 宽度大于 950 像素：固定左侧栏；规则和表单可以双栏。1100 像素以下适当缩小内容边距。
- 宽度不超过 950 像素：侧栏变为顶部区域，导航按三列自适应换行，外观切换继续可见。
- 宽度不超过 650 像素：规则和表单改单栏，导航按两列自适应换行，保持正常字号，内容左右边距约 16 像素，页面标题降为 24 像素。

390 像素宽窗口是常规验收尺寸。长词条、模型说明、错误信息必须换行；页面不产生横向滚动，按钮和保存状态不能挤出可视范围。

## 组件约定

**卡片**围绕一个任务组织内容。标题、表单和动作依次排列，仅在影响使用判断时增加说明；“想多看”和“想少看”卡片可以用顶部细色线区分。

**按钮**使用短动词或明确动作名称，例如“添加”“开始分析”“采用所选建议”。主要动作使用实心蓝色，次要动作使用中性描边。被禁用的按钮不能点击，需要的前置条件在附近说明，不能只靠变淡让用户猜。

**开关**的文字在左、控件在右，名称直接说明作用，不默认附加解释。可使用组件库的开关，必须保留可访问名称、开启状态和键盘操作；分析建议的多选保持复选框语义，不伪装成开关。

**词条**使用可换行的小标签按钮，显示词条与删除符号。点击删除后提供最近一次撤销。计数显示在分组标题旁；空组显示“尚未添加词条”。

**输入框**有独立标签，占位文字只给例子，不承担字段名称。数字限制写在相关字段附近；输入无效时保留值，显示可处理的错误。多行输入允许竖向调整高度。

**图标**保持现有轻量线条风格，可复用风格一致的组件配套图标，品牌图标保留；大小、线宽和文字对齐保持一致。装饰图标不重复朗读；只有图标的操作必须有明确名称，例如“查看 DeepSeek 密钥”。

左上角的品牌小电视允许眨眼、轻跳两下、左右张望、开心眯眼和天线抖动。进入页面后等待 2–4 秒，之后每次动作结束间隔 15–30 秒随机播放一种，眨眼出现得更频繁；动作不改变布局。页面在后台或系统开启减少动态效果时保持静止。

## 自动保存与反馈

自动保存是默认编辑方式，不另加手动保存流程。界面应区分“正在输入”“正在写入”“已经保存”，不能提前显示成功。

| 内容或动作 | 保存约定 |
| --- | --- |
| 开关、模型参数、数字参数 | 修改后暂停约 200 毫秒再保存；连续修改合并处理 |
| 四组词条 | 回车、点击添加或离开输入框时加入规则，然后自动保存；输入到一半不自动生成词条 |
| 删除或撤销词条 | 立即更新界面，再自动保存 |
| 近期计划 | 输入变化后自动写入；遵守当前字数限制，失败保留输入 |
| 各项服务密钥 | 和参数一样在暂停输入后自动保存；已保存的值默认隐藏，可用眼睛按钮显示；清空后自动删除 |
| 分析建议 | 用户勾选后点击“采用所选建议”，再自动保存；不默认勾选或自动采用 |
| 外观切换 | 立即生效并记住选择，独立于业务设置保存 |
| 导入备份 | 先展示摘要与密钥处理结果，明确确认后导入 |

密钥采用当前的“输入自动保存、清空删除”方式，不恢复旧版的“留空保留”“另设移除开关”或“离开输入框才保存”。显示与隐藏只改变可见性，不触发密钥修改。

中文输入法选字时，回车不能误触发词条添加；普通回车添加，按住 Shift【配合回车输入换行】时保留换行。批量输入继续支持逗号、分号和换行分隔，去重沿用既有规则。

页头保存状态统一使用“等待保存…”“正在保存…”“已自动保存”“有修改未保存”“保存已暂停”。正常保存保持安静，不弹出反复确认或每次成功提示。

保存过程必须满足以下约定：

1. 保存期间可以继续编辑，返回的旧结果不能覆盖新输入；后续修改按顺序继续保存。
2. 校验或写入失败后保留修改，解释原因并提供重试，不对同一失败内容循环自动重试。改为有效内容或恢复已保存值后，状态恢复正常。
3. 另一个设置页更新配置时，空闲页面同步更新；本页有修改时保留输入并暂停保存。重新读取前说明将放弃本页未保存修改。
4. 旧读取结果不能把版本、计划或保存基线退回；计划保存失败后，切换窗口或重新获得焦点也不能丢失输入。
5. 仍有未保存修改、写入或分析进行中时，保留离开页面的提醒。开始分析和导出备份前，相关修改须已保存且没有冲突。
6. 保存完成以本机写入成功为准。成功后异步通知已打开的 B 站页面，通知发送、页面回执及通知失败均不能占住保存队列；页面恢复焦点时主动读取最新规则。

## 文案与分析交互

功能名称已能说明用途时，不再附加重复解释。确有必要的条件、费用和数据发送范围用正常可读字号简短表达；计数、时间和状态可以使用次级文字。实现细节、算法与固定请求限制写入使用文档，不将原来的冗长解释全部搬进折叠区。技术参数和分析历史可展开，需要采取行动的错误不能藏起来。四组词条共用一条添加提示；标签匹配使用“包含词条即可／与词条完全一致”的明确选项。

| 场景 | 表达方式 |
| --- | --- |
| 规则卡片 | 想多看／高亮匹配的视频；想少看／遮住匹配的视频 |
| 计划输入引导 | 输入框内给一个具体计划示例，不额外堆叠引导句 |
| 条件冲突开关 | 同时匹配时，优先保留“想多看”的内容 |
| 保存失败 | 暂时没能保存：具体原因。旁边提供“重试”。 |
| 采用建议 | 已采用选中的建议，规则会自动保存。 |

避免“赋能”“智能化提升”“为您提供全方位”等宣传句，也避免把内部状态、完整请求过程和存储实现搬到日常说明里。服务名称、模型标识和业务空间标识需要准确，不能为了口语化改写成含糊昵称。发送内容、费用和密钥明文等与用户决策有关的信息，在对应操作附近简短说明，不反复堆叠。

手动分析仍由用户点击开始。生成中显示阶段与逐步出现的说明；预览不是可立即采用的最终建议。需要补充信息时，模型选项、“自定义”和“跳过，直接分析”并列。等待补充回答时保持本次会话，暂时锁定计划与规则编辑，提供结束本次澄清的入口。

新增、删除建议必须显示文字标记与理由。旧计划对应的建议可查看，但不能直接采用；严格模式继续保护最后一个偏好词条。取消、断流或无效结果保留上次完成的分析。

### 设置页配色与交互调查（2026-10-14）

通过用户预先打开的两个 B 站首页标签页读取页面配色，并查看深浅色截图。浅色使用白色卡片、浅灰底色，主文字为 #18191C【深灰文字】，边框为 #E3E5E7【浅灰分隔线】；深色使用 #17181A【卡片背景】、#101011【页面背景】，主文字为 #E7E9EB【浅灰文字】，边框为 #2F3134【深灰分隔线】。品牌蓝和粉色分别作为选中状态、偏好/避开词条的点缀，文字颜色适当加深或提亮以保持可读。

设置页保留三个分区，使用卡片、细边框、开关和短文案。外观默认跟随系统，手动选择只保存在设置页本机存储中，不改变过滤配置和备份格式。开关和参数暂停输入约 650 毫秒后自动保存；词条在回车、点击添加或离开输入框时加入，密钥在离开输入框后保存。保存失败保留输入；保存期间的新修改接着写入；跨页版本冲突暂停写入。模型分析和付费复核的调用条件保持原有规则。

## BiliBuff视频助手

视频助手只处理当前正在播放的内容，不提供分P选择、列表或批量管理。保留字幕、总结、章节、问答和下载五个入口；视频页底部“AI 设置”仅跳转设置面板。参数放在“日常功能 → 视频助手”，总结、章节和问答分别配置服务、模型、思考强度、输出上限和上下文容量。常用自动功能开关置顶，默认关闭。

以粉色电视图标和 BiliBuff 品牌字建立辨识度，不放无功能的顶部色条；使用中性色卡片、16像素圆角和胶囊式分页。正文保持14像素，原文时间、引用和有效的媒体信息可使用12–13像素。删除口号、缓存提示、重复计数、空态第二段说明和每条回答后的模型时间小字；生成来源仍保存在结果数据中，不替换成当前所选模型。成功反馈一句话，错误保留可行动的信息。

面板样式隔离，宿主明确恢复自身点击能力，不能修改B站右栏的禁用状态。卡片内不重复显示灰字视频标题和总时长。网页全屏和播放器全屏时隐藏助手，退出后恢复原位置。深浅色、窄栏、键盘焦点、字幕跟随与全屏布局均需验收。

总结采用 AI SDK【模型调用与结构化流式输出】和 json-render【预设组件组合渲染】，固定顶部一句结论及必要条件，模型自由选择、排列和组合核心要点、步骤、对比、因果链、观点依据和时间线六类内容组件。通常1–3个区块，每组默认展示最多3项，额外条目及论据按需展开；关键限制直接可见。窄栏对比仅并列两个对象，因果链最多四节点，不生成无依据评分或装饰图表。所有关键条目以真实字幕行号定位，完整校验后启用跳转；增量只展示字段完整且引用有效的组件，不写缓存。复制、导出和评论背景使用同一结果派生的完整文本，包含折叠详情；旧文字总结继续可读，无需自动重新生成。

总结和问答直接在正文区流式显示，不放蓝色生成预览卡片。章节自带内容优先显示真实标题和时间，隐藏AI生成按钮；生成章节先展示结构化预览，完成校验后接入播放器底栏、跳转菜单和进度条分段标记。下载格式自动读取，仅失败时给出重试入口。
