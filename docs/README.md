## 文档维护约定

- 项目只维护浏览器扩展。专题文档使用中文文件名，按用途放入对应分类；项目首页、扩展入口和本目录保留标准说明文件名，方便工具识别。
- 使用指南说明当前操作；开发设计说明实现约定；调查保存机制与证据；版本记录保存历史取舍和验证状态。
- 同一主题的复查合并到原专题，独立机制拆分成专题；不要新建混放所有内容的综合调查日志。
- 调查结论保留日期、来源和未验证范围；旧版本的“当前”“已实现”“待验收”均按当时背景理解，后续实现以源码和新的验证结果为准。
- 新增或移动文档时同步维护本目录、相关专题及入口链接；大表和请求明细单独存放并从正文引用。
