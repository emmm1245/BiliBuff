# BiliBuff - 哔哩哔哩｜B站效率与体验增强插件

上B站学点东西，有个Buff更顺手。

推荐筛选、留白首页、观看统计，以及按需使用的 AI 计划分析、内容复核和评论区速读，为 B 站学习与日常浏览添点助力。

本项目只提供浏览器扩展，支持桌面版 Chrome 和 Edge。

- 第一次用：看[安装步骤](../docs/使用指南/扩展安装与迁移.md#安装)，装好后点“BiliBuff 设置”。
- 换浏览器：看[备份与迁移](../docs/使用指南/扩展安装与迁移.md#备份与浏览器间迁移)，带上你的规则和记录。
- 想了解整个项目：回[项目首页](../README.md)。
- 想改代码：看[完整开发指南](../docs/开发设计/扩展开发与验收.md)和[文档目录](../docs/README.md)。
